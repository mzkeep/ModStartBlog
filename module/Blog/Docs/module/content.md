## 模块介绍

「个人博客」提供了一个简约的模块系统

```mind
功能特性
    图文博客
    博客分类
    博客标签
    博客归档
    博客评论
    友情链接
    留言本
    关于博主
    暗黑/白天主题
    批量导入
```

## 功能特性

- 图文博客：支持图文文章发布与管理
- 博客分类：文章多级分类管理与筛选
- 博客标签：标签云与标签文章聚合
- 博客归档：按时间维度归档历史文章
- 博客评论：文章评论与留言本互动
- 友情链接 / 留言本 / 关于博主
- 暗黑/白天主题：暗黑模式跟随系统
- 批量导入：博客文章批量导入支持

## 使用场景

- 个人博客与技术专栏
- 企业资讯与公告发布
- 内容型站点的文章管理

## 模块入口

- `/blog` 博客首页
- `/blog/about` 关于博主
- `/blog/message` 留言本
- `/blog/tags` 标签云
- `/blog/archive` 文章归档
- `/blogs` 博客列表
- `/blog/{id}` 文章详情
